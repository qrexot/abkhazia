ШТАБ АБХАЗИИ — ОПЕРАТИВНО-СТРАТЕГИЧЕСКАЯ КАРТА (РЕАЛЬНЫЕ ПУТИ, ЖД, АВИАЦИЯ + ЗАЩИЩЁННЫЙ ОНЛАЙН 1 НА 1)

БЫСТРАЯ НАСТРОЙКА ОНЛАЙН-ИГРЫ 1 НА 1 (GITHUB PAGES + SUPABASE — ОДИН РАЗ):
1. Откройте ваш проект на https://supabase.com -> SQL Editor -> New Query.
2. Вставьте целиком файл supabase/schema.sql и нажмите Run (создаст таблицы, жёсткий RLS-античит, SHA-256 токены и 7 RPC-функций).
3. Впишите ваш Project URL и Anon Public Key один раз в файл game/net/supabase_config.js и залейте на GitHub Pages (или введите их через кнопку «Онлайн 1×1» в шапке сайта).
4. Нажмите «Онлайн 1×1» -> выберите один из 18 сценариев -> «Создать комнату» -> нажмите «Копировать» и отправьте ссылку другу (?room=ABK-XXXX).
5. Друг открывает ссылку, нажимает «Войти за Восток (Б)», вы жмёте «Начать матч» — игра идёт в реальном времени с защитой от читов и автовосстановлением после F5.

АВТОНОМНАЯ ИГРА:
Без настройки Supabase сайт полностью работает локально (Запад / Восток против ИИ, 1 на 1 Hotseat, Наблюдатель / Миссия ООН).
